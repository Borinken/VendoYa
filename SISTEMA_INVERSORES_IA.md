## 🔧 CONFIGURACIÓN

### 1. Obtener API Key de OpenAI

```bash
# 1. Ve a: https://platform.openai.com/api-keys
# 2. Crea cuenta (si no tienes)
# 3. Click "Create new secret key"
# 4. Copia la key (empieza con sk-proj-...)
```

### 2. Configurar en el proyecto

Edita `.env.local`:

```bash
OPENAI_API_KEY=sk-proj-TU_KEY_AQUI
```

### 3. Desplegar a Vercel

```bash
cd /Users/LeslyHector/vendoya-crm

# Configurar variable en Vercel
vercel env add OPENAI_API_KEY

# Pegar tu key cuando lo pida

# Desplegar
vercel --prod
```

## 📱 CÓMO USAR

### 1. Accede a la plataforma:
```
https://tu-dominio.vercel.app/dashboard/investors
```

### 2. Completa el formulario:
- **Precio**: Precio de compra de la propiedad
- **Ubicación**: Ciudad y zona
- **m²**: Metros cuadrados
- **Habitaciones**: Número de habitaciones
- *Opcional*: Alquiler estimado, gastos, año construcción

### 3. Click "Analizar Inversión"
- Espera 30 segundos mientras IA analiza
- Ve score, ROI, cashflow, proyección

### 4. Comparte con inversor:
- Descarga PDF del análisis
- Envía por WhatsApp/Email
- **Cierra la venta**
